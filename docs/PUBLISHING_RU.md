# Как опубликовать QBT Camera (памятка для владельца)

## 1. GitHub: залить проект на свой (другой) аккаунт

### Шаг 1. Решить, что будет видно всем

| Вариант | Что видят люди | Плюсы | Минусы |
|---|---|---|---|
| **A. Публичный репозиторий с кодом** | всё: код, README, скриншоты, релизы | проект легко найти, вызывает доверие | код можно подсмотреть (лицензия запрещает копировать, но не спасает от «честных» воров) |
| **B. Два репозитория** (рекомендую для продажи) | публичный `qbt-camera`: README, скриншоты, инструкция, лицензия, релизы со сборкой. Приватный `qbt-camera-source`: весь код | находят так же, код в безопасности | два репозитория |

### Шаг 2. Создать репозиторий на GitHub

1. Войдите в нужный аккаунт на <https://github.com>.
2. Справа вверху **+** → **New repository**.
3. **Repository name:** `qbt-camera` (для варианта B ещё один, `qbt-camera-source`, с галочкой **Private**).
4. **Description:** `Your iPhone as a pro webcam for Windows — USB/Wi‑Fi, LiDAR depth blur, background replacement, chroma key, LUTs`.
5. **Public** или **Private** — по выбранному варианту.
6. **Ничего не добавляйте** (без README, .gitignore, лицензии): всё уже есть у нас.
7. **Create repository**. Скопируйте адрес вида `https://github.com/ИМЯ/qbt-camera.git`.

### Шаг 3. Отправить код (в терминале, в папке проекта)

```bash
git remote add origin https://github.com/ИМЯ/qbt-camera.git
git branch -M main
git push -u origin main
```

При первой отправке откроется окно входа GitHub (Git Credential Manager). Войдите **именно в тот аккаунт**, куда заливаете.
Если окно автоматически вошло в другой аккаунт: Панель управления → Диспетчер учётных данных → Учётные данные Windows → удалите `git:https://github.com` и повторите `git push`.

> В истории коммитов указан автор `QBT <1itstep.ai@gmail.com>`. Если на публичной странице нужна другая почта, скажите, и я поменяю автора до отправки.

### Шаг 4. Чтобы проект находили

На странице репозитория нажмите ⚙ справа от **About**:
- **Website:** ссылка на релизы или сайт, если появится.
- **Topics:** `iphone-webcam`, `webcam`, `virtual-camera`, `windows`, `ios`, `continuity-camera`, `obs`, `zoom`,
  `background-blur`, `background-removal`, `chroma-key`, `green-screen`, `lidar`, `truedepth`, `lut`,
  `teleprompter`, `streaming`, `directx`, `swiftui`.

Ещё: **Settings → General → Social preview → Upload** `docs/screenshots/windows-portrait.png`. Эта картинка будет показываться при пересылке ссылки.

### Шаг 5. Выпустить версию (скачивание для Windows)

1. Соберите пакет: `powershell -ExecutionPolicy Bypass -File scripts\make_release.ps1 -Version 1.0`. Получится `release\QBTCamera-Windows-1.0.zip`.
2. На GitHub: **Releases → Draft a new release → Choose a tag** `v1.0` → заголовок `QBT Camera 1.0`.
3. Перетащите `QBTCamera-Windows-1.0.zip` в окно, коротко опишите возможности и нажмите **Publish release**.

> Windows может показать «Windows защитила ваш компьютер» (SmartScreen), потому что программа не подписана сертификатом. Пользователь нажимает **Подробнее → Выполнить в любом случае**. Это предупреждение убирает сертификат подписи кода (≈ $100–400 в год). Можно купить позже.

## 2. iPhone: App Store без $99, увы, невозможен

- App Store и TestFlight доступны **только** участникам Apple Developer Program: **$99 в год**, даже для бесплатных приложений. Взнос не берут только с некоммерческих, учебных и государственных организаций.
- **Бесплатно сейчас:** установка через Xcode с бесплатным Apple ID (инструкция в `docs/MANUAL.md`, раздел 3). Ограничения: нужен Mac, установка действует 7 дней, потом её нужно повторить нажатием Run в Xcode.
- **Когда будете готовы платить $99:**
  1. <https://developer.apple.com/programs/enroll/> → оплатить.
  2. Сказать мне, и я подготовлю: иконки и скриншоты нужных размеров, описание для App Store (EN), ссылку на политику конфиденциальности (`PRIVACY.md`, можно прямо с GitHub), сборку через Archive и отправку в App Store Connect.
  3. Проверка Apple обычно занимает 1–3 дня.
